# Hospital Management System

A full-stack web-based Hospital Management System designed to simplify and manage essential healthcare operations.

## Features

- Patient registration and login
- Doctor login and management
- Doctor listing with specialization and experience
- Appointment booking
- Appointment status management
- Double-booking prevention
- Prescription management
- Patient appointment and prescription tracking
- Doctor dashboard with appointment statistics

## Technologies Used

- Python
- Flask
- SQLite
- HTML
- CSS
- JavaScript

## Project Overview

This project provides separate workflows for patients and doctors, making it easier to manage appointments, prescriptions, and basic hospital-related activities through a simple web interface.
